- **T000/T001 — delivered history:** T000 established the static toolchain and shell. T001 implemented the labelled booking fixture and browser learning loop. Passing frontend checks do not verify database persistence, source accuracy, or same-build project reuse.

Validate strict request shape, project-scoped IDs/relations/assets, supported scenes, revision conflicts, and transactional batches. Enforce foreign keys per connection, parameterized SQL, controlled asset registration/serving, loopback access, cross-origin write rejection, and an explicit local write credential. Test restart persistence, failed-write rollback, historical snapshots versus current facts, scoped partial updates, backup/restore of database plus assets, and CI/build/runtime serving. Root guidance now describes the implemented API/storage runtime. Verified 2026-09-25: 31 unit/integration tests, 16 browser tests, both builds, artifact boundaries, fresh install and production restart/shutdown; independent review findings fixed. No push, remote CI result or public release is claimed.
